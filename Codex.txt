You are a software engineer responsible for implementing and testing the capabilities of AI models on the UI/UX improvement subtype within the Feature & improvement category.
Your task is to deliver a Python-based implementation that performs UI/UX restructuring, hierarchy correction, section grouping, interaction optimization, attachment-preview enhancement, and mis-operation prevention for an Online Course Platform “Course Detail Page” scenario.
The implementation must simulate layout transformation and interaction-behavior improvements (before → after), handling edge cases, malformed structures, mixed-type fields, ambiguous section definitions, and deeply nested layout trees while ensuring correctness and robustness.
You must also generate automated test cases and a fully reproducible environment to verify your implementation. Produce two separate project folders representing the baseline and improved versions.
Ensure all necessary setup files (e.g., requirements.txt, setup.sh), test code, and automated run scripts (e.g., run_tests.sh) are included so every test runs via a single command. Each project must additionally output at least one HTML prototype file so reviewers can visually inspect the baseline and enhanced UI states.

Description
This experiment evaluates AI models’ ability to implement and optimize UI/UX improvements for an overloaded Online Course “Detail Page.”
Current pain points:
• Oversized hero pushes key information below the fold
• Long linear sections lack modular grouping
• No persistent CTA in view; users scroll to the footer to enroll
• Instructor, syllabus, and reviews span full width, reducing scannability
• Mobile view remains dense and slow
• Attachment or syllabus previews open fullscreen, blocking context
The improved version (Project B) must deliver:
• Information hierarchy restructuring with a pinned “Course Info Card” (price, tags, CTA)
• Default-collapsed syllabus/reviews/related courses
• Card-based visual hierarchy with background segmentation and spacing
• Clear separation between public descriptions and internal author notes
• Non-blocking attachment previews (side panel or inline hover)
• Confirmation prompts for enrollment/payment actions
• Reduced interaction friction (mobile bottom CTA, fewer scrolls, anchored navigation)
• Safe degradation for missing modules, invalid types, malformed layout trees, and unsafe HTML
• Automatic generation of HTML prototypes per project to validate the UI visually
Key evaluation criteria:
• Correctness of the transformation
• Improvement in information hierarchy and cognitive load reduction
• Handling malformed inputs, hidden vulnerabilities, and mixed types
• Accuracy of grouping/collapsing nested structures
• Automated test coverage for transformations and edge cases
• Reproducible environment with one-command execution
• Quantitative metrics: hierarchy clarity, scroll-length reduction, edge-case coverage ratio
